# PR. 2 Analyzer – Excel Sales Analysis

## 📊 Project Overview
**PR. 2 Analyzer** is an Excel-based sales analysis and business intelligence project.  
The project analyzes customer sales, products, regions, monthly trends, discounts, and profit using advanced Excel features.

## 🎯 Objectives
- Analyze total sales and profit performance
- Identify high-value customers
- Compare sales across regions and product categories
- Analyze monthly sales growth
- Perform descriptive statistics
- Perform linear regression between Sales and Profit
- Use What-If Analysis to understand discount impact on profit
- Build charts and a KPI dashboard
- Present business insights using data storytelling

## 📌 Main Analysis

### 1. Customer Analysis
- Find high-value customers based on total sales
- Use customer names with lookup formulas
- Apply filtering and conditional formatting

### 2. Regional Analysis
- Compare sales across different regions
- Analyze regional contribution to total sales
- Use Pivot Tables for summary analysis

### 3. Product Analysis
- Compare sales across product categories
- Identify product categories with higher sales
- Visualize product performance using charts

### 4. Monthly Sales Analysis
- Analyze monthly sales trends
- Calculate month-over-month growth
- Add up/down indicators for growth

### 5. Profit Analysis
- Analyze the relationship between sales, discount, and profit
- Use What-If Analysis to understand the effect of changing discounts

### 6. Statistical Analysis
- Calculate descriptive statistics
- Perform linear regression using Excel Data Analysis ToolPak
- Study the relationship between Sales and Profit
